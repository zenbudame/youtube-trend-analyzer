# YouTube Trend Analyzer — チャンネル規模フィルター対応版

既存の人気動画・キーワード分析・ゲーム比較・狙い目ランキング・長期トレンド・CSV出力を維持したStreamlitアプリです。外部データベースや有料サービスの追加は不要です。

## 今回の追加

- 全5タブで共通の登録者数フィルター：0〜1,000人未満、1,000〜1万人未満、1万〜10万人未満、10万〜100万人未満、100万人以上、任意入力。
- 任意入力は最小値・最大値を含む範囲です。上限なしも選べます。プリセットは重複を避けるため上限未満です。
- チャンネル総再生数・公開動画本数の最小/最大条件。
- 動画一覧と動画CSVに登録者数・公開状態・チャンネル総再生数・動画本数・登録者比を追加。
- 「小規模で伸びている動画を探す」：初期条件は登録者1万人以下、登録者比3倍以上。登録者比順、再生速度順、再生数順でも表示できます。
- 最低動画再生数、登録者比の下限、Shorts候補/長尺条件。
- 比較・長期分析で使った個別動画も展開して確認・CSV保存できます。
- 取得済みデータへの条件変更は追加のAPIリクエストなしで反映されます。

## 使い方の例

1. 左側の登録者数の規模を「1,000〜1万人未満」にする。
2. 「小規模で伸びている動画を探す」をオンにする。
3. 必要なら動画再生数の最小を1,000にする。
4. キーワード分析でゲーム名、直近7日または30日、取得件数100〜200件を選んで「分析する」。
5. 登録者比順で動画を確認する。条件が厳しく0件なら、範囲を広げるか検索語・取得件数を調整する。

APIは登録者数で動画を直接検索できないため、まず再生数上位の動画を検索し、その後でチャンネル条件を適用します。取得件数は絞り込み前の件数です。小規模の動画を網羅する検索ではありません。0件は市場に該当動画がないことを意味しません。ゲーム比較は最大10タイトルです。

## 登録者数と欠損値

`channels.list(part=statistics)` の `subscriberCount`、`hiddenSubscriberCount`、`viewCount`、`videoCount` を使用します。

- 非公開は「非公開」、応答にチャンネル/登録者数がない場合は「取得不可」と表示し、数値は欠損のまま保持します。0人に置き換えません。
- 登録者数0人は公開された0として扱いますが、登録者比は算出しません。
- 登録者比＝動画の現在の累計再生数÷チャンネルの現在の登録者数。非公開・取得不可・0人の比率は空欄（表では欠損表示）です。無限大や0倍にしません。
- 非公開等は、登録者数条件なしなら含める/常に除外/非公開等のみを選べます。登録者数・登録者比の数値条件がある場合、不明な値は条件を満たしません。
- 総再生数・動画本数も取得できなければ欠損とし、それらの数値条件から除外します。
- APIの登録者数は丸められた値です。境界付近の判定・登録者比は概算です。動画本数は公開動画本数です。

## API呼び出しの節約

動画の `channelId` を重複除去して50件ずつ一括取得します。ゲーム比較/狙い目ランキングでは全タイトル分、長期分析では全区間分をまとめてチャンネル取得します。同じチャンネルの動画ごとにAPIを呼びません。

API応答とキーワード検索結果は15分間キャッシュします（ディスクには保存しません）。APIキーもキャッシュの識別に含むため別キーの結果とは混同しません。条件変更・ランキング順変更・CSV取得で再検索はしません。

検索100件なら通常は検索2回、動画詳細2回、チャンネル取得は重複除去後のチャンネル数÷50の切り上げ回数です。再検索やゲーム数・期間を増やすとクォータを使います。最新の割当はGoogle Cloud Consoleで確認してください。

## 無料Web公開・既存アプリの更新

1. ZIPを解凍し、`app.py`、`analyzer.py`、`requirements.txt`、README等をGitHubリポジトリのルートに配置します。**今回追加のanalyzer.pyも必須です。** ZIPそのものをアップロードしないでください。
2. 既存アプリは同じリポジトリのファイルを更新します。エントリポイントは引き続き `app.py` です。
3. 新規の場合はStreamlit Community CloudでGitHubを接続して「Create app」、対象リポジトリと `app.py` を指定します。
4. Pythonは3.11以降を使用してください。依存関係はrequirements.txtからインストールされます。
5. Community CloudのSecretsに次を設定します（既存設定があればそのまま使用）。

```toml
YOUTUBE_API_KEY = "取得したAPIキー"
```

キーをGitHubやソースコードへ書かないでください。保存済みキーはサーバーで読み、画面入力欄には埋め込みません。Secrets/環境変数にキーがない場合だけ手動入力欄を表示します。

Community Cloudの無料ホスティングとYouTube APIの利用枠の範囲で運用する構成です。公開アプリの訪問者も保存済みキーのクォータを消費します。常時稼働や無制限利用は保証されません。Google Cloud側でYouTube Data API v3を有効にし、API制限を設定してください。

## ローカル起動

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

macOS/Linuxでは `.venv/bin/python` を使用してください。キーは起動後に入力するか、環境変数 `YOUTUBE_API_KEY`、または `.streamlit/secrets.toml` で設定できます。

## 指標と既存機能の注意点

- 動画トレンドスコア：再生速度45%、高評価率25%、コメント率15%、登録者比15%の順位百分率を加重合計。
- ゲーム比較：中央値再生速度55%、サンプル内チャンネル数25%、中央値高評価率20%。
- 狙い目：中央値再生速度40%、登録者比25%、エンゲージメント15%、サンプル内競合の少なさ20%。
- 比率不明は比率の加点を0にするだけで、表示する比率は欠損のままです。条件一致0件のゲームは表に残し、スコア/順位の対象外にします。
- スコアは条件を満たしたサンプル内の相対評価で、YouTube公式指標ではありません。競合数や総再生数を市場全体の値として解釈しないでください。
- 長期分析は元版と同じく30日区間で最大24区間を検索します。期間表示を実際の日付範囲にしました。投稿区間別の「現在の累計再生数」であり、その月に発生した再生数ではありません。チャンネル規模も現在の値です。
- 地域コードJPは日本で視聴可能な動画の条件で、日本語や日本人の投稿だけに限定しません。
- Shorts候補は長さ180秒以下での推定で、縦横比等による厳密な判定ではありません。
- 動画CSVは既存の英語列名を維持し、`channel_total_views`、`channel_video_count`、`subscriber_status` を追加しています。
